================================================================================
          GPU EVOLUTIONARY ECOSYSTEM SIMULATION ENGINE - SPECIFICATION
================================================================================
Engine Vision: High-performance, large-scale Artificial Life (ALife) engine
Target Hardware: NVIDIA Tesla T4 GPU (Google Colab Free Tier, CuPy/CUDA)
Target Scale: ~1,000,000 active entities @ 60 FPS real-time / 1000+ FPS headless
Memory Architecture: Structure of Arrays (SoA) 100% resident in VRAM
Trigger Keyword: ooga booga

--------------------------------------------------------------------------------
1. HETEROGENEOUS ENTITY BUFFERS & MEMORY FOOTPRINT
--------------------------------------------------------------------------------
Entity Data Architecture is split into 3 distinct SoA buffers to optimize 
VRAM cache efficiency and memory alignment:

[1] ANIMAL BUFFER (Herbivores, Carnivores, Omnivores, Sanguivores, Detritivores)
    - Footprint: 85 Bytes / Agent (65 Quantized Variables)
    - Capacity: 200,000 - 500,000 Agents (~17 - 42.5 MB VRAM)

[2] PLANT / RESOURCE BUFFER
    - Footprint: 12 Bytes / Entity (6 Variables)
    - Capacity: 1,000,000+ Plants (~12 MB VRAM)
    - Variables: GRID_X (INT16), GRID_Y (INT16), BIOMASS (UINT8), 
                 MAX_BIOMASS (UINT8), PLANT_TYPE (UINT8), GROWTH_RATE (UINT8), 
                 PLANT_FLAGS (UINT32 Bitmask)

[3] PATHOGEN / DISEASE BUFFER
    - Footprint: 16 Bytes / Strain (9 Variables)
    - Capacity: 10,000 Strains (~0.16 MB VRAM)
    - Variables: STRAIN_ID (INT32), VIRULENCE (UINT8), LETHALITY (UINT8), 
                 MUTATION_RATE (UINT8), INCUBATION_TIME (UINT8), 
                 TRANSMISSION_TYPE (UINT8), TARGET_HOST_DIET (UINT8), 
                 RECOVERY_RATE (UINT8), DISEASE_FLAGS (UINT32 Bitmask)

Total VRAM Footprint for 1.2M+ Entities: ~45 - 85 MB (< 0.5% of T4 VRAM)

--------------------------------------------------------------------------------
2. COMPLETE ANIMAL BUFFER LAYOUT (65 VARIABLES - 85 BYTES)
--------------------------------------------------------------------------------
Subsystem A: Kinematics & Spatial Physics (14 Bytes)
  0. GRID_X               [INT16] : World Tile X (0 - 65,535)
  1. GRID_Y               [INT16] : World Tile Y (0 - 65,535)

  3. SUB_Y                [UINT8] : Sub-pixel Offset Y (0 - 255)
  4. VEL_X                [FP16]  : Velocity X
  5. VEL_Y                [FP16]  : Velocity Y
  6. ACC_X                [FP16]  : Acceleration X
  7. ACC_Y                [FP16]  : Acceleration Y

  8. ENERGY               [UINT8] : Current fuel pool (0-255 -> 0-100%)
  9. MAX_ENERGY           [UINT8] : Maximum energy cap

 11. HYDRATION            [UINT8] : Water level

Subsystem C: Drive-Reduction Deficits (10 Bytes) [Deficit = Target - Current]

Subsystem D: Mutable Genetics & Phenotypes (25 Bytes)

 36. GENE_DETRITIVORE     [UINT8] : Corpse / rotting waste digestion capability

--------------------------------------------------------------------------------
3. WORLD RULES & ENVIRONMENT MECHANICS
--------------------------------------------------------------------------------
1. Map Geometry & Migration Boundary:
   - World divided into 3 Biomes: Tundra (Top), Temperate (Mid), Desert (Bottom).
   - Boundary Soft Mask: Agents wandering too far past outer world edges are 
     flagged as "Migrated Out" and recycled to bound VRAM usage.

2. Energy Cycle & Fertilizer Soil:
   - Closed thermodynamic loop.
   - Dying agents drop Corpse Nodes. Rotting corpses deposit Soil Fertilizer 
     into specific grid cells, boosting future plant growth rates locally.

3. Water Bodies & Aquatic Transition Gene:
   - Fixed lakes/rivers painted across grid tiles.
   - Dynamic Gene: GENE_AQUATIC_SPECTRUM (0 - 255):
     * 0-64 (Hydrophobic): Slowed/damaged in water; minimal water intake.
     * 65-190 (Terrestrial/Amphibious): Normal land animal; drinks at water edge.
     * 191-255 (Fully Aquatic/Fish): Suffocates on land; max speed in water.

4. Corpse Decay & Disease Vectors:
   - Corpse Biomass = GENE_SIZE * 100.
   - Eaten fresh by Carnivores/Omnivores, decaying by Detritivores.
   - Highly infected corpses act as environmental pathogen hot spots.

--------------------------------------------------------------------------------
4. GPU MUTATION ENGINE (WEIGHTED TIER SYSTEM)
--------------------------------------------------------------------------------
Mutations are evaluated in parallel on GPU using a weighted random distribution:
  - Low Roll (85% chance)  : 0.1% - 2% shift (Micro-tuning/stasis)
  - Med Roll (14% chance)  : 3.0% - 10% shift (Gradual adaptation)
  - High Roll (1% chance)  : 20.0% - 50% shift (Macro-jump / Speciation event)

All mutations are applied in 1 GPU clock pass using vectorized CuPy/CUDA tensors.

--------------------------------------------------------------------------------
5. GPU PERFORMANCE SYSTEMS
--------------------------------------------------------------------------------
- GPU-Native Spatial Hash Grid: Atomic grid binning reduces distance math 
  from O(N^2) to O(N) linear time in VRAM.
- Kernel Fusion: Core drive updates, metabolism, and movement executed in a single 
  pass to maximize L1 cache hit rate.
- Zero PCIe Bottleneck: Simulation loop remains 100% inside VRAM; CPU is only 
  used to launch asynchronous GPU kernel commands.
